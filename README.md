## Governança

Este repositório segue a governança comum do ecossistema do autor (bloco no `AGENTS.md`, mantido no hub
`mancano-tales/mancano-repo-hub`). Em resumo: tarefas complexas começam por um plano em
`repo-governance/plan/`, e todo plano ativo tem uma issue neste repositório
(`python tools/plano_issue.py criar <plano>`), onde os agentes se coordenam.
