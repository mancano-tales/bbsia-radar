# Dados públicos dos relatórios

Esta pasta é a fronteira dos arquivos preparados para publicação. Coloque aqui
somente saídas pequenas que já passaram por revisão e foram aprovadas para
divulgação. Rascunhos, cache bruto, textos integrais de README/model card, dados
pessoais, tokens e resultados não revisados ficam fora dela.

Ainda não há rodada nem contrato de dados público. O esquema será definido a
partir de uma amostra real, dos resultados do Decifra e da revisão humana; não
use a exportação de corpus (`id`, `text`, `source_urls`) como dataset do site.

Depois de uma saída curada ser versionada aqui, o workflow de Quarto recompila o
site. O próprio radar não publica nem faz deploy automaticamente ao coletar.
